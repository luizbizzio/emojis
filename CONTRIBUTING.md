# Contributing to the Emoji Licensing Guide

The guide lives in [`README.md`](README.md). A useful correction names the exact emoji set, identifies its publisher and version where possible, and links to the license published by that project.

## Review a change

- Check that the cited license covers the artwork itself. Look for separate terms covering code, trademark use, attribution, and modified assets.
- When adding or editing a row, keep the commercial use, modification, redistribution, and attribution columns consistent with the source. Link the official terms and note the date you checked them.
- If rights are unclear or vary by asset, describe the uncertainty in the table. Use links to source artwork for evidence.

In the pull request, include the changed row or section and the source that supports each change in licensing status.
